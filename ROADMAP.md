# Roadmap

Each phase ends with a working build, green tests, updated documentation and a focused commit.

1. **Phase 1 — Foundation:** MV3 side panel, fixture search, schema, validation, storage and URL-only context boundary. Complete.
2. **Phase 2 — Editorial pilot:** five researched indicators, schema v2, provenance, content-quality rules and comparison pilot. Complete.
2.5. **Phase 2.5 — MACD flagship candidate:** dedicated journey, eight synthetic visual lessons, interactive parameter lab, five strategy frameworks, relationship map and failure lab. Complete; awaiting user evaluation before it becomes a universal template.
2.6. **Phase 2.6 — Reusable learning engine:** shared learning shell, modular math/visualization registry, four additional Gold Standard experiences, integration dry run and 55-test regression suite. Complete.
2.7. **Phase 2.7 — Proposed validation checkpoint:** conduct unfamiliar-indicator learning sessions, record comprehension/friction evidence, refine shared modules and editorial review workflow without expanding indicator count. Requires explicit approval.
   - **2.7A — Unfamiliar Indicator Batch 1:** TRIX, CHOP, Aroon, Vortex and STC. Ten total experiences. Complete.
   - **2.7B — Next batch:** not started; indicator selection and learning findings require explicit user approval.
3. **Phase 3 — Useful v0.1:** blocked until explicit user approval. Human-review the pilot, improve navigation/accessibility, add editorial tooling, then grow toward approximately 30 reviewed indicators in small batches.
4. **Phase 4 — Optional context convenience:** isolated, permission-conscious experiments; manual search remains authoritative.
5. **Phase 5 — Visual education:** locally generated, licensed/synthetic annotated examples.
6. **Phase 6 — Relationship engine:** overlap, complementarity and missing-dimension analysis.
7. **Phase 7 — Educational strategy composition:** guardrailed examples and risk framing.
8. **Phase 8 — Optional AI:** retrieval over reviewed content with enforced citations.

Coverage milestones are 5 reviewed indicators, then 30, then 100+, with a data model capable of 1,000+ entries and aliases.
