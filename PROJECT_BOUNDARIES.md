# Project Boundaries

## Included in the open-source project

TradingView Indicator Academy includes the reusable learning engine, the fifteen approved indicator implementations, formula tests, synthetic educational scenarios, knowledge entries, search, accessibility-oriented side-panel UI, extension packaging, public documentation, and reproducible build tooling.

Public contributions may improve formulas, tests, educational explanations, translations, accessibility, visualizations, and additional indicators after review.

## Outside the project

Private trading systems, unpublished research, account or broker records, credentials, personal data, private API integrations, commercial secrets, unreleased commercial prototypes, and founder-only operational documents are not part of this repository. Do not submit them in issues, pull requests, fixtures, screenshots, or logs.

Future confidential or proprietary work should use a separate private repository and a clean interface boundary. Moving GPL-covered derivative code into another repository does not by itself remove GPL obligations.

## Legal and product boundaries

- The public code is offered under GPL-3.0-only; no artificial field-of-use restriction is added.
- Contributors retain copyright in their contributions unless a separate, explicit agreement says otherwise.
- Repository governance controls the official repository and releases, not lawful forks.
- The project contains educational tools, not financial advice, guaranteed signals, or verified profitability claims.
- This project is independent and is not affiliated with, sponsored by, or endorsed by TradingView.
